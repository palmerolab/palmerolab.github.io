# crisie.github.io

Personal academic website for Cristina Palmero.

## Pages

- `index.html` is the home page and biography
- `research.html` covers research themes and ECASIS
- `projects.html` is a self contained account of projects, datasets, and selected work
- `engagement.html` covers public engagement and presentations
- `students.html` covers PhD opportunities and prospective student guidance
- `news.html` contains research news and milestones

## Local preview

This is a static site with no build dependency. Serve the repository root with any local HTTP server, for example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

The site is designed for GitHub Pages and uses static HTML pages at the repository root. Publishing is intentionally not automated in this repository.
